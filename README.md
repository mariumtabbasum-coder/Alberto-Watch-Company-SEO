## 📖 Overview

**Alberto Watch Company** is a front-end web development project built to represent a premium watch brand through an elegant website interface.

The website focuses on presenting watch collections, organizing company information, and creating a visually appealing user experience with a sophisticated design.

The project combines **HTML5, CSS3, Bootstrap 5, and JavaScript** to build the website's structure, styling, responsive layouts, and interactive functionality.

It was developed as part of my Software Engineering learning journey to strengthen my practical web development skills and apply front-end concepts in a real-world-style project.

## 🎯 Project Objectives

- Build a professional-looking website for a watch company.
- Present watch collections in an organized and attractive layout.
- Create a consistent visual identity across website sections.
- Apply responsive web design principles.
- Practice HTML, CSS, Bootstrap, and JavaScript.
- Improve skills in website layout, navigation, styling, and user interaction.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- A modern web browser, such as Google Chrome.
- [Visual Studio Code](https://code.visualstudio.com/).
- [Git](https://git-scm.com/) (optional, if you want to clone the repository).

### Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/mariumtabbasum-coder/Alberto-Watch-Company.git
```

### Navigate to the Project Folder

```bash
cd Alberto-Watch-Company
```

### Open in Visual Studio Code

```bash
code .
```

## 💻 How to Run the Project

1. Open the project folder in Visual Studio Code.
2. Locate `index.html`.
3. Open the file in your browser, or use the **Live Server** extension for a local development server.
4. Explore the website and its available features.

**Note:** Bootstrap, Bootstrap Icons, Font Awesome, and Google Fonts use external CDN resources. An internet connection may be required for these resources to load.
